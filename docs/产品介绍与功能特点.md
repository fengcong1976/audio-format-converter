# 音频格式转换工具 · 产品介绍与功能特点

## 一句话

拖进来选个格式，转完就在原文件旁边。

## 使用场景

- 手机录的 m4a 要发给只能用 mp3 播放的设备
- 无损 flac 太大，想压成 mp3 存手机
- 一段长录音只想留中间 20 分钟
- 视频里的背景音乐想单独拿出来听

## 功能要点

### 格式互转

- 支持读入 mp3 / wav / flac / m4a / aac / ogg / wma / ape / opus / aiff
- 可以输出 mp3 / m4a / ogg（有损）与 flac / wav（无损）
- 视频文件拖进来会自动只取第 1 条音轨

### 批量处理

- 一次拖多个文件，或直接拖整个文件夹
- 文件夹会连子文件夹一起找，自动跳过上次生成的 `out`
- 结果按文件原名写到它旁边的 `out`，同名自动加序号

### 码率与音质

- 有损格式可选保持原码率 / 320k / 192k / 128k / 64k
- 「保持原码率」按源文件的真实平均码率走：ogg / Vorbis 这类可变码率的标称值常虚高（标称 500k、实际 108k），程序用「体积 ÷ 时长」反推，最多 192k，转完不会反而变大
- 可以「限制大小」：填一个 MB 上限，码率按目标体积自动反推；转完复称体积，略超会自动降一档重编一次，仍超会如实写在说明里
- 无损格式（flac / wav）没有码率概念，码率与限制大小都会自动置灰
- 源编码与目标编码一致且没有任何处理时走直通，不重新编码，音质与原文件一致

### 剪切、音量、淡入淡出

- 按秒填起始与结束，结束填 0 = 一直到最后
- 起始 ≥ 结束、结束超过总时长，都会用一句人话说明，不会静默截断
- 音量 0%–200%（100% = 不改动）；淡入淡出填秒数，0 = 关
- 音频比淡入淡出还短时自动收小，并在说明里写清

### 逐条报告

- 结果表显示：格式怎么变、码率从多少到多少、时长、体积变化、状态
- 双击任意一行看完整详情：是否重新编码、采样率、声道、音量、淡入淡出、来源、有损说明、原文件是否改动
- 每个 `out` 里另存一份 `report.json`，方便留档与核对

### 隐私与安全

- 全程本地调用随包的 ffmpeg，不联网、不上传
- 底部常驻「本次 0 次联网」实测结果
- 原文件只读不写，处理前后比对 SHA-256

## 系统要求

- Windows 10 / 11 64 位
- 免安装版解压即用；安装包按当前用户安装，不弹 UAC

## 已知限制

- 不做多文件合并
- 不做波形可视化剪辑，只按秒数切
- 不做变声 / 变调 / 降噪 / 响度标准化
- 不做 CD 抓轨与版权保护内容（`.m4p` 等会直接提示不处理）
- 不做视频画面处理
