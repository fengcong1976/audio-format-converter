# 第一次转换：三步出结果

- 摘要: 从拖入文件到找到结果，讲清第一次完整转换要做的三件事，以及结果默认落在哪里。
- 关键词: 音频转换, mp3 转 wav, 批量音频转换
- 排序: 1

## 导语

这个工具只做一件事：把音频（或视频里的音轨）转成你要的格式。它不联网、不上传，也不会改动原文件。第一次用，照下面三步走即可。

## 开始之前

- 确认要转的文件在本机（U 盘、移动硬盘都可以）
- 想好要转成什么格式：mp3 / m4a / ogg 体积小但有损；flac / wav 无损但文件大
- 不需要另外安装 ffmpeg，程序旁边自带

## 操作步骤

### 1. 把文件拖进窗口

把音频或视频文件拖到窗口上方的虚线区域，也可以点「选择文件」或「选择文件夹」。

- 支持一次拖多个文件，或直接拖一个文件夹（会连子文件夹一起找）
- 文件类型支持 mp3 / wav / flac / m4a / aac / ogg / wma / ape / opus / aiff，以及 mp4 / mkv / mov / avi 等视频
- 加进来后，列表会显示文件名、格式、码率、时长与大小

### 2. 选输出格式和码率

在「输出格式」里选目标格式，在「码率」里选码率。

- 输出可以是 mp3 / m4a / ogg（有损），或 flac / wav（无损）
- 码率选「保持原码率」最省心：按文件体积反推真实码率，ogg 这类「标称很高、实际很低」的文件转完也不会变大
- 想更小可以选 128k 或 64k；要给微信 / 邮箱留额度，就勾「限制大小」填一个 MB 上限，码率自动算
- 选 flac / wav 时码率与「限制大小」会自动置灰：无损格式没有码率这个概念

### 3. 点「开始转换」，然后去 out 里拿结果

点右下方的「开始转换」，进度条走完就完成了。

- 结果写在每个文件旁边的 `out` 文件夹里，例如 `音乐\out\歌声.mp3`
- 如果已经存在同名文件，会自动变成 `歌声 (1).mp3`，不会覆盖
- 原文件始终保持原样，不会被删除或改写
- 想再打开结果文件夹，点底部的「打开结果文件夹」

## 常见问题

### Q: 结果文件到底在哪？我找不到。

A: 在源文件所在文件夹里的 `out` 子文件夹。例如源文件是 `D:\音乐\歌声.flac`，结果就在 `D:\音乐\out\歌声.mp3`。转完程序会自动打开一次；之后可以点底部「打开结果文件夹」再看。

### Q: 为什么 mp3 转 mp3 也有意义？

A: 两种情况有用：一是改码率（比如 320k 压到 128k 省空间），二是只改封装或只做剪切、音量、淡入淡出。如果源编码与目标编码一致且没有任何处理，程序会走直通，不重新编码，音质与原文件一致——结果表的「说明」列会写「未重新编码（原音频直通）」。

### Q: 转换会不会动到我的原文件？

A: 不会。程序对原文件只读不写，结果一律写到独立的 `out` 文件夹；每条处理前后都会比对原文件的 SHA-256，并在详情页写明「原文件是否改动」。
